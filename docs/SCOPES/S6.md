# SCOPE BRIEF: S6 — Merge Queue (Protected Differentiator)

- **Goal:** Sequentially rebase, test in a temporary worktree, and fast-forward merge (`git merge --ff-only`) approved task branches onto the base branch, halting safely with full logs on any conflict or test failure and recovering cleanly after crashes.
- **Appetite:** 5 working days
- **Demo script:** Queue 3 approved tasks, watch sequential rebase + test + fast-forward merge with Pause and Stop-after-current controls; test halting on a failing test in task 2 leaving base branch cleanly at task 1.
- **Acceptance tests:**
  1. Queue processes approved tasks strictly one at a time: checks base branch cleanliness, rebases task branch onto current base tip in an isolated temporary integration worktree, runs `test_command`, and fast-forwards base branch (`git merge --ff-only` / `git update-ref` when base is not dirty) only if tests pass.
  2. On rebase conflict (`git rebase --abort` cleanly restores state) or test failure, queue stops immediately, marks the offending task `Failed` with logs attached, leaves base branch untouched at the previous successful task, and offers "Ask agent to resolve".
  3. Supports `Pause` and `Stop after current`.
  4. Crash recovery cleans up leftover temporary queue worktrees and surfaces interrupted queue state on restart.
