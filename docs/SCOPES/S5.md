# SCOPE BRIEF: S5 — Conflict Forecast (Protected Differentiator)

- **Goal:** Forecast pairwise merge conflicts across all active task branches using `git merge-tree --write-tree -z`, cache results by commit SHA pair, display the interactive conflict matrix, and compute a greedy suggested merge order.
- **Appetite:** 3 working days
- **Demo script:** With 4 active task branches (including a deliberate 2-file conflict pair), open the Conflict Matrix screen, inspect clean (`✓ clean`) vs conflicted (`✗ N files`) cells, view the suggested merge order with reasoning, click a conflict cell to view files and send a resolution prompt to the agent, then add a commit to one branch and confirm only its row/column recomputes.
- **Acceptance tests:**
  1. `conflicts_compute` runs `git merge-tree --write-tree -z <a> <b>` with bounded concurrency across $N(N-1)/2$ pairs.
  2. Exit code `0` -> `Clean`; exit code `1` -> `Conflicted` with exact file paths parsed from the NUL-delimited Conflicted file info section; any other exit code -> `Error` (never treated as clean).
  3. Results cached in SQLite `conflicts` keyed by canonical `(min_sha, max_sha)` so unchanged pairs are never recomputed.
  4. Suggested merge order ranks tasks greedily by fewest conflicts first, breaking ties by smaller total changed lines, with human-readable explanation.
