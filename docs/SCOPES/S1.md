# SCOPE BRIEF: S1 — Repository and Worktrees

- **Goal:** Open a git repository (`>= 2.38`), persist it in SQLite, and safely create, list, and delete isolated sibling git worktrees with backup patches.
- **Appetite:** 3 working days
- **Demo script:** Open a repo, create three worktrees, attempt to delete one with uncommitted changes (refused with clear prompt), force-delete it and verify `.patch` backup is written, restart app and confirm remaining worktrees persist.
- **Acceptance tests:**
  1. `repo_open` verifies `git >= 2.38`, checks valid git repo, detects base branch (`main`/`master`/current), and persists in SQLite `repos`.
  2. `create_worktree` creates `<repo-parent>/<repo-name>.worktrees/<slug>` on branch `antfarm/<id>-<slug>`.
  3. `list_worktrees` parses `git worktree list --porcelain` accurately, including paths with spaces.
  4. `remove_worktree` refuses uncommitted/untracked changes unless `force = true`, and saves a backup `.patch` file before forced removal.
  5. Strict git subcommand allowlist and canonicalized path containment checks block traversal and forbidden commands (`clean`, `reset --hard`, `push --force`).
- **Must-haves:** SQLite schema initialization, `git` safety module, real temporary-repo integration tests (including paths with spaces).
- **No-gos:** Force push, `git clean`, `git reset --hard`.
