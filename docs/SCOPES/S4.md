# SCOPE BRIEF: S4 — Review: Diff and Tests

- **Goal:** Enable complete single-screen review of a task's changes against the base branch (per-file lazy loading, unified/split diff, line counts) and test execution per commit hash, plus Approve, Revise, and Discard actions.
- **Appetite:** 4 working days
- **Demo script:** Open a completed task, inspect file list and diff in Changes tab, run test command in Tests tab with live output and recorded commit SHA pass/fail, then test Approve, Ask agent to revise, and Discard (confirming backup patch).
- **Acceptance tests:**
  1. Diff output matches `git diff <merge-base>..HEAD` per file, loads individual file diffs lazily so large files/repos never freeze the UI, and supports keyboard navigation.
  2. Test runner executes repo's `test_command` inside the task worktree with timeout support, streams output, and stores `passed`, `commit_sha`, `duration_ms`, and `log_path` in `test_runs`.
  3. Approve transitions `NeedsReview -> Approved`; Revise sends prompt to agent terminal and transitions `NeedsReview -> Running`; Discard saves a backup patch and transitions to `Discarded`.
