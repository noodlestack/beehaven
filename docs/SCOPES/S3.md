# SCOPE BRIEF: S3 — Tasks, Board, and Agents

- **Goal:** Implement the nine-state task state machine with crash recovery, Claude Code and Generic agent adapters with hook/silence waiting detection, concurrency slot limiting (default 4), and the grouped task board UI.
- **Appetite:** 5 working days
- **Demo script:** Add 5 tasks; observe 4 start immediately (`◐ Running`) and 1 wait (`○ Queued`); trigger an agent prompt and watch card move to `▲ Waiting for you` at the top of the board; kill/restart app and verify crash reconciliation.
- **Acceptance tests:**
  1. Single state-transition function enforces allowed transitions across all 9 states (`Queued`, `Running`, `WaitingForYou`, `NeedsReview`, `Approved`, `Merging`, `Merged`, `Failed`, `Discarded`) and logs every event to `events`.
  2. Startup crash recovery reconciles SQLite task states with disk worktrees and live PIDs.
  3. Claude Code adapter writes `.claude/settings.local.json` (excluded via `.git/info/exclude`) pointing `Notification` and `Stop` hooks to the authenticated local listener; Generic adapter supports configurable command + output-silence heuristic + manual state toggle.
  4. Concurrency limiter starts queued tasks automatically as slots open (default 4).
  5. Every UI status badge displays shape mark + text label + semantic token role (never color alone).
