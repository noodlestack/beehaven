# SCOPE BRIEF: S2 — Embedded Terminals

- **Goal:** Provide a live, Rust-owned `portable-pty` terminal session per worktree with ~16 ms output batching, rolling replay buffer, resize, and full process-tree termination that survives UI reloads.
- **Appetite:** 4 working days
- **Demo script:** Open a worktree terminal in `xterm.js` (WebGL enabled), run a 10-second output flood without UI freeze, reload the window and observe replayed terminal history, resize terminal, and kill session with zero orphan child processes.
- **Acceptance tests:**
  1. Output reader pushes into bounded channel and flushes batched chunks every ~16 ms.
  2. Rolling ring buffer (in memory + log file on disk) replays recent output upon UI reconnect.
  3. Killing a session terminates the entire process tree (`taskkill /T /F` on Windows / process group kill on Unix).
  4. Fake-agent fixture tests verify spawn, stdin write, resize, flood handling, reconnect replay, and kill.
- **Must-haves:** `xterm.js` + `@xterm/addon-fit` + `@xterm/addon-webgl` + optional screen-reader mode toggle.
